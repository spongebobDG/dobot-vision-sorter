# Engineering decisions and trade-offs

이 문서는 최종 구현에서 선택한 방법과 포기한 대안을 설명합니다. 정량 결과가 없는 선택은 성능 우위가 아니라 설계 가설로 구분합니다.

## Instance segmentation instead of object detection

블록의 클래스와 중심만 필요하다면 bounding box 모델이 더 단순하고 빠를 수 있습니다. 이 프로젝트는 그리퍼 정렬에 사용할 물체 외곽과 회전각이 필요해 instance segmentation을 선택했습니다.

마스크에는 추가 비용과 한계도 있습니다.

- 폴리곤 라벨링 비용이 bounding box보다 큽니다.
- 정사각형 블록은 90° 대칭이므로 작은 마스크 노이즈에도 기준 변이 바뀔 수 있습니다.
- 현재 구현은 종횡비가 임계값보다 작은 물체의 각도를 0°로 처리합니다.

최종 벤치마크에서는 detection 모델과 segmentation 모델의 지연시간 및 픽업 성공률을 함께 비교할 예정입니다.

## Homography plus object-height correction

고정 카메라와 평면 작업대에서는 2D 호모그래피가 구현과 디버깅이 단순합니다. 하지만 테이블 평면에서 계산한 행렬을 블록 상단 중심에 바로 적용하면 시차가 발생하므로 카메라 중심과 높이를 이용한 보정을 추가했습니다.

카메라가 기울어져 있거나 높이가 크게 변하는 환경에서는 이 가정이 약해집니다. 그런 환경에서는 다음 대안을 검토해야 합니다.

- 카메라 intrinsic/extrinsic calibration과 3D ray-plane intersection
- 깊이 카메라
- eye-in-hand hand-eye calibration

## Held-out coordinate validation

호모그래피는 최소 4개 대응점으로 결정되기 때문에 같은 4점에서 재투영 오차를 계산하면 실제 정확도를 과대평가할 수 있습니다. 따라서 보정점과 검증점을 분리하고, 검증 기준을 통과하지 않은 파일은 런타임에서 거부합니다.

보고할 지표는 평균값 하나가 아니라 mean/P95/max 오차입니다. 최대 오차는 작업 영역 모서리의 위험을 드러내는 데 중요합니다.

## Reject unsafe targets instead of clamping

범위 밖 좌표를 가장 가까운 경계값으로 바꾸면 프로그램은 계속 동작하지만, 원래 의도하지 않은 위치로 로봇이 이동합니다. 이는 인식 또는 보정 실패를 숨깁니다.

최종 구현은 원본 목표 좌표를 검사하고 범위를 벗어나면 즉시 중단합니다. 가용성보다 예측 가능한 실패를 우선한 선택입니다.

## Re-detect after every placement

한 프레임에서 여러 물체를 검출하고 모두 순차 처리하면 처리 중 물체가 움직이거나 카메라/로봇 진동이 발생해 뒤쪽 좌표가 오래된 값이 됩니다. 최종 구현은 한 물체만 집고 스캔 위치로 돌아와 새 프레임을 취득합니다.

이 방식은 처리량이 감소하지만 좌표 신뢰성과 실패 분석이 단순해집니다. 향후 처리량 최적화는 다중 객체 추적과 장면 변화 감지를 추가한 뒤 진행합니다.

## Placement feedback is opt-in

카메라로 배치 오차를 반복 보정하는 기능은 구현되어 있지만 기본값은 꺼져 있습니다. 그리퍼가 카메라를 가리거나 물체 높이가 보정 가정과 달라지면 오히려 오차가 커질 수 있기 때문입니다.

독립 좌표 검증과 반복 배치 실험에서 수렴성이 확인된 환경에서만 활성화합니다. 후보 선택도 전체 화면 최고 confidence가 아니라 목표점 반경 내 동일 클래스의 가장 가까운 물체로 제한합니다.

## Public repository scope

학습 이미지, 장비별 calibration, 모델 가중치, 원본 영상은 저장소에서 제외했습니다.

- 데이터는 출처·수집·분리 방법만 문서화합니다.
- 모델은 데이터 버전과 평가 결과가 준비된 뒤 GitHub Release로 공개합니다.
- 장비별 설정은 `configs/local.yaml`에서 관리합니다.
- README에는 재현 가능한 결과만 기록하고 미측정 값은 `TBD`로 유지합니다.
