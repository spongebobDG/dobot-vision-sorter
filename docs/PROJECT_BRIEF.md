# Project brief

## One-line summary

YOLOv8 인스턴스 세그멘테이션으로 정상/불량 블록의 위치와 각도를 추정하고, 검증된 카메라-로봇 좌표 변환을 통해 Dobot이 안전하게 자동 분류하도록 구현한 비전 기반 로봇 프로토타입입니다.

## Problem

검출 모델이 출력하는 픽셀 좌표는 로봇이 바로 사용할 수 없으며, 잘못된 좌표 하나가 충돌이나 오배치로 이어질 수 있습니다. 또한 카메라 영상에서 정확히 보이더라도 물체 높이에 따른 시차, 그리퍼 회전, 작업 중 장면 변화가 실제 픽업 성공률에 영향을 줍니다.

## Solution

1. YOLOv8 세그멘테이션 마스크에서 클래스, 중심, 회전각을 계산합니다.
2. 호모그래피와 물체 높이 보정으로 픽셀을 로봇 좌표로 변환합니다.
3. 미사용 검증점 기준을 통과한 calibration만 실행에 사용합니다.
4. 작업 영역과 중앙 pick zone을 모두 통과한 물체만 선택합니다.
5. 안전 높이에서 XY 이동과 회전을 수행하고 저속으로 하강합니다.
6. 한 물체를 배치한 뒤 새 프레임을 촬영해 오래된 좌표 사용을 방지합니다.
7. 오류 시 임의 좌표 보정이나 강제 배치를 하지 않고 동작을 중단합니다.

## Why segmentation

Bounding box만으로도 분류와 대략적인 중심 계산은 가능하지만, 그리퍼 정렬에 사용할 물체 외곽과 회전각을 함께 얻기 위해 instance segmentation을 선택했습니다. 정사각형에 가까운 블록의 각도는 불안정할 수 있어 종횡비 임계값 아래에서는 대칭 물체로 처리합니다.

## Verified evidence

- 64.7초 실제 장비 동작 영상
- 좌표·데이터·선택·용량 로직 단위 테스트 12개
- GitHub Actions CI 통과
- 기존 데이터의 cross-split 중복 10장 검출
- 범위 밖 원본 좌표 즉시 거부
- 독립 검증에 실패한 calibration 로드 거부

## Evidence boundary

영상은 물리 시스템의 동작을 보여주지만 모델 정확도, 배치 오차, 장기 반복 성공률을 수치로 입증하지는 않습니다. 기존 데이터 분리에는 누수가 있었으므로 과거 mAP를 사용하지 않으며, 새 세션 기반 train/val/test가 준비된 뒤 다음 지표를 측정합니다.

- 클래스별 precision, recall, F1 및 mask mAP
- 추론 지연시간과 FPS
- 미사용 좌표의 calibration mean/P95/max 오차
- 최소 100회 pick·분류·배치 성공률과 사이클 시간

## Key interview discussion points

- 왜 detection 대신 segmentation을 선택했는가?
- 4점 호모그래피의 거의 0mm 오차가 왜 실제 정확도가 아닌가?
- 잘못된 비전 좌표가 로봇 명령으로 전달되지 않도록 어떻게 막았는가?
- 여러 물체를 한 번에 처리하지 않고 매 사이클 재검출하는 이유는 무엇인가?
- 정량 성능을 과장하지 않으면서 프로토타입의 가치를 어떻게 입증했는가?
