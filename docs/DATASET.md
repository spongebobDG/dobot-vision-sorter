# Dataset protocol

## Prototype audit

기존 프로토타입 자료를 감사한 결과는 다음과 같습니다.

- 고유 이미지 50장
- 세그멘테이션 객체 276개: 정상 135개, 불량 141개
- 검증 이미지 10장이 학습 폴더에도 byte-identical 상태로 존재
- 약 2분 46초 동안 같은 배경과 조명에서 촬영

따라서 기존 검증 점수는 최종 포트폴리오 성능으로 사용하지 않습니다.

## Recommended collection

한 번의 긴 동영상을 프레임으로 나누는 것보다 독립 촬영 세션을 여러 개 구성합니다.

- 날짜와 시간대가 다른 세션
- 조명 방향과 밝기가 다른 세션
- 블록 개수, 위치, 회전, 겹침 정도가 다른 세션
- 카메라 그림자와 로봇 팔 가림이 포함된 실패 조건
- 깨끗한 블록과 다양한 결함 크기

각 이미지에는 세션 ID를 기록하고, 같은 세션의 연속 프레임이 여러 split에 흩어지지 않도록 합니다.

## Split policy

권장 방식은 세션 단위 분리입니다.

- `train`: 모델 학습
- `val`: 임계값과 하이퍼파라미터 선택
- `test`: 마지막에 한 번만 사용하는 최종 평가

`scripts/audit_dataset.py`는 byte-identical 중복을 찾지만, 약간 다른 연속 프레임까지 찾아내지는 못합니다. 세션 메타데이터 기반 분리가 함께 필요합니다.

## Label quality

- YOLO 세그멘테이션 폴리곤은 블록 외곽을 따라야 합니다.
- 클래스 정의를 `normal=0`, `defect=1`로 고정합니다.
- 자동 라벨은 반드시 사람이 검수합니다.
- 자동 라벨을 만든 모델과 동일한 모델의 예측만으로 품질을 확인하지 않습니다.
- 빈 이미지와 오탐 유도 배경도 별도로 포함합니다.

python scripts/audit_dataset.py data/processed
